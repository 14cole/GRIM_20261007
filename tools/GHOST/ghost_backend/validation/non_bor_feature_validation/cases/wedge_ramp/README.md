# External full-wave case: wedge/ramp

This directory defines the first arbitrary-face-orientation reference case.
It contains no solver result and must not be cited as validation evidence until
all four GRIM artifacts below have been generated by independent solves and
the GHOST assembly workflow.

Use `case_spec.json` as the geometry and convention contract.  The featured
body carries the same open panel gap and compact fastener installation on a
sloped ramp and on a horizontal control deck.  The paired placements isolate
normal handling and local-frame rotation without changing feature family.

The required output layout is:

```text
cases/wedge_ramp/
    clean_truth.grim
    clean_prediction.grim
    featured_truth.grim
    featured_prediction.grim
```

- `clean_truth.grim`: independent converged 3-D Maxwell solve of the clean
  body.
- `clean_prediction.grim`: that clean response after the exact import path
  used by Assembly.
- `featured_truth.grim`: independent converged solve with all specified
  features explicitly meshed.
- `featured_prediction.grim`: `clean_prediction` plus the installed-minus-
  clean point deltas and OPN-FRD line deltas placed by GHOST.

Run the validator from `tools/GHOST` after filling the directory:

```text
python ghost_backend/validation/reconstruction.py --manifest geometry_tests/non_bor_feature_validation/cases/wedge_ramp/feature_case.json --report geometry_tests/non_bor_feature_validation/cases/wedge_ramp/report.json
```

Copy `feature_case.template.json` to `feature_case.json`; do not relax a gate
without recording the physical or convergence reason.  Mesh-converge clean
and featured models as a pair, and confirm that their numerical delta changes
less than the GHOST reconstruction error.  The validator applies no fitted
amplitude, phase, range, or coordinate correction.
