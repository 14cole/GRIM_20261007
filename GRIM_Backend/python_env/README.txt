Extract your Windows x64 embeddable Python ZIP into this folder.
The intended release runtime is Python 3.14.6.
The resulting path must be GRIM_Backend\python_env\python.exe.
Keep the supplied ._pth file; GRIM setup handles isolated startup.

Use matching wheels and the same Python release across distributed copies.
This repository is a skeleton; supply the runtime on the other computer.
Double-click Setup_GRIM.bat in the GRIM root folder to download matching
wheels and complete setup. Afterward, use the root Launch_GRIM.bat.
For offline setup, follow ..\offline packages\README.txt.
